# Catálogo de Jogos (Flutter)

**Integrantes:** Caue Yohan Plachi

Catálogo de produtos (jogos de tabuleiro) com tela de detalhes, área "Transformações"
(map/toList) e histórico do ciclo de vida do app.

## Como executar
Se as pastas de plataforma (android/) não existirem, gere-as uma vez:

```
flutter create . --platforms=android
flutter pub get
flutter run
```
